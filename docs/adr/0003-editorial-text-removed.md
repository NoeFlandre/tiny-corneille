# ADR 0003: Editorial text is removed

## Context

Each Gutenberg tome holds Corneille's plays. It also holds the editor's notices, variant lists, footnotes and an index.

## Decision

- Remove the editor's notices, the variant lists and complements, the footnotes, the front matter and the index.
- Keep the plays, Corneille's own prefaces, discourses and examinations.
- Keep the original spelling.

## Consequences

- The corpus holds Corneille's words only.
- Some editor text remains where the layout differs. See [Technical debt](../tech-debt.md).
